# Боты в Телеграме и Max

Боты нужны, чтобы члены клуба не заходили на сайт ради каждой мелочи. Сайт остаётся главным,
бот — быстрый способ ответить и получить напоминание. Боты в Телеграме и Max умеют одно и то же,
можно включить один или оба. Человек может подключить оба мессенджера, тогда сообщения приходят в оба.

Бот умеет:

- присылать ссылку для входа на сайт (сообщение «вход»);
- рассылать мероприятия с кнопками «Еду», «Не знаю», «Не еду». Очередь на места та же, что на сайте: кто первый нажал «Еду», тот едет, остальным бот сообщает место в листе ожидания;
- принимать «я оплатил 3000». Бот переспрашивает, заводит черновик оплаты и присылает начфину сообщение с кнопками «Подтвердить» и «Отклонить». Когда начфин нажимает кнопку, бот сообщает члену итог;
- отвечать на «долг»: сколько человек должен или переплатил в текущем сезоне;
- напоминать должникам о взносах, мягко, с кнопкой «Я оплатил N ₽».

## 1. Регистрация бота

### Телеграм

Завести бота может любой человек, бесплатно, за пару минут.

1. В Телеграме откройте @BotFather и отправьте `/newbot`.
2. Введите название, например «TeamUp — ОК №178», и имя бота латиницей, которое заканчивается на `bot`, например `ok178_teamup_bot`.
3. BotFather пришлёт токен вида `123456:ABC...`. Это пароль бота: никому его не показывайте и не кладите в репозиторий.

### Max

Завести бота в Max может только самозанятый, ИП или организация. Личного аккаунта недостаточно.

1. Оформите самозанятость в приложении «Мой налог» (через Госуслуги, бесплатно). Если доходов нет, налога нет.
2. Зайдите на платформу «MAX для партнёров», войдите по номеру телефона, выберите статус «самозанятый» и подтвердите его через Госуслуги.
3. Создайте бота: название (до 59 символов, без эмодзи), описание (до 200 символов) и логотип 500×500. Например: «TeamUp — ОК №178», описание «Взносы, выезды и напоминания охотколлектива ОК №178».
4. Дождитесь модерации (до 48 часов в рабочие дни), статус станет «Опубликован».
5. В разделе «Настройки» скопируйте «Токен доступа». Это пароль бота: никому его не показывайте и не кладите в репозиторий.

## 2. Настройка

В файле `.env` на сервере заполните строки того мессенджера, который включаете:

```
APP_URL=https://адрес-сайта

TELEGRAM_BOT_TOKEN=токен от @BotFather
TELEGRAM_BOT_NAME=имя бота без @
TELEGRAM_WEBHOOK_SECRET=длинная случайная строка из латинских букв и цифр

MAX_BOT_TOKEN=токен из «Настроек»
MAX_BOT_NAME=имя бота из его ссылки https://max.ru/имя_бота
MAX_WEBHOOK_SECRET=длинная случайная строка
```

Случайную строку можно получить командой `openssl rand -hex 32`.

## 3. Запуск

Боты получают сообщения одним из двух способов.

**Вебхук**, когда у сайта есть домен с HTTPS. Мессенджеры сами присылают сообщения на `APP_URL/api/telegram` и `APP_URL/api/max`. Подключается один раз:

```bash
npm run bot:webhook
```

**Опрос**, на своём компьютере или на сервере без домена. Боты сами забирают сообщения, пока работает команда:

```bash
npm run bot:poll
```

Одновременно включайте только один способ. Опрос Телеграма сам отключает его вебхук.

Если Телеграм с российского сервера работает плохо, опрос можно запустить на другом сервере
(например, за границей): ему нужны только `.env` и доступ к базе.

## 4. Как члены клуба подключаются

- **По ссылке.** На странице «Состав» админ нажимает «Ссылка для Телеграма» или «Ссылка для Max» у нужного человека и пересылает её ему. Человек открывает ссылку, нажимает «Начать», и бот его узнаёт. Ссылка одноразовая и действует 7 дней.
- **По номеру телефона.** Человек сам находит бота и нажимает «Поделиться номером». Если этот номер записан у него в «Составе», бот его узнаёт. Принимается только свой номер: чужую карточку контакта бот не примет.

## 5. Рассылки

- **Мероприятие.** На странице мероприятия кнопка «Разослать в мессенджеры». Сообщение уходит всем, кто участвует в сезоне и подключил мессенджер. Под кнопкой показано, кто без мессенджера.
- **Долги.** На странице «Взносы» у начфина кнопка «Напомнить должникам в мессенджерах». Тем, кто уже заявил оплату на весь долг, напоминание не приходит.
- **Напоминание по расписанию.** Пока не прошёл срок уплаты взноса сезона, команда ничего не шлёт, после срока напоминает:

  ```bash
  npm run remind-debts -- ok178
  ```

  На сервере её ставят в расписание (cron), например по понедельникам в 10:00:
  `0 10 * * 1 cd /srv/teamup && npm run remind-debts -- ok178`

## Устройство

| Файл | Что внутри |
| --- | --- |
| `src/bot/types.ts` | общий язык ботов: входящие события, сообщения с кнопками |
| `src/bot/telegram-api.ts`, `src/bot/max-api.ts` | обращения к API мессенджеров и перевод их событий в общий вид |
| `src/bot/commands.ts` | разбор текста («я оплатил 3000») и данных кнопок, тесты рядом |
| `src/bot/handler.ts` | ответы на сообщения и кнопки, одни для обоих мессенджеров; проверка, что человек состоит в клубе и имеет право |
| `src/bot/notify.ts` | рассылки: начфину, членам о мероприятии, должникам |
| `src/app/api/telegram/route.ts`, `src/app/api/max/route.ts` | адреса вебхуков, проверяют секреты |

Без токенов сайт работает как раньше, а кнопки рассылок отвечают «Боты в мессенджерах ещё не подключены».

Документация: Telegram Bot API — https://core.telegram.org/bots/api, Max — https://dev.max.ru/docs-api.
Адреса API можно переопределить переменными `TELEGRAM_API_URL` и `MAX_API_URL`, например для проверки на имитации.
