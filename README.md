# TeamUp

Веб-приложение для клубов по интересам: охотколлективов, рыболовных и спортивных клубов, любых сообществ с общим бюджетом и совместными мероприятиями.

Что умеет (в разработке, см. [план](docs/plan.md)):

- состав клуба и роли: начфин, председатель, член;
- взносы и штрафы, частичные оплаты, черновики «я оплатил» с подтверждением начфином, долги и депозиты с переносом на следующий сезон;
- расходы по статьям бюджета с фото чеков;
- мероприятия с откликом «еду / не еду», лимитом мест и листом ожидания;
- годовой отчёт и выгрузка в Excel;
- бот в мессенджере Max для уведомлений.

## Устройство

| Папка | Что внутри |
| --- | --- |
| `src/app` | страницы сайта (Next.js) |
| `src/db/schema.ts` | схема базы данных: все таблицы с комментариями |
| `src/domain` | расчёты без базы: долги, места на выезде, штрафы, годовой отчёт; рядом тесты |
| `src/seed` | формат файла начальной загрузки клуба |
| `scripts` | загрузка клуба из файла, годовой отчёт в консоли |
| `drizzle/` | миграции базы, генерируются из схемы |
| `docs/plan.md` | план продукта, роли, этапы, хостинг |

Стек: TypeScript, Next.js, PostgreSQL, Drizzle ORM, Vitest. Деньги хранятся в копейках целыми числами.

## Запуск на своём компьютере

Нужны Node.js 22 и Docker.

```bash
cp .env.example .env
docker compose up -d db      # база PostgreSQL
npm install
npm run db:migrate           # создать таблицы
npm run dev                  # сайт на http://localhost:3000
```

Загрузить пример клуба и посмотреть его отчёт:

```bash
npm run seed -- examples/demo-club.json
npm run report -- demo
```

Формат файла загрузки описан в `src/seed/format.ts`.

Проверки перед изменениями:

```bash
npm run typecheck
npm test
```

После правки `src/db/schema.ts` создайте миграцию: `npm run db:generate`.

## Данные

Реальные данные клубов (Excel-файлы, выгрузки, паспортные данные) в репозиторий не кладутся никогда: `.gitignore` отсекает `data/`, `*.xlsx` и `*.csv`. Для примеров используется выдуманный клуб.
